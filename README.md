# えいたんチャレンジ

小学校6年生向けの、中学準備英単語クイズです。添付済みの単語リストから、重複を除いた157語を収録しています。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く。
2. 「5問チャレンジ」または「10問チャレンジ」を選ぶ。
3. 日本語を見て英単語を入力し、「答え合わせ」を押す。

学習記録は使ったブラウザの中だけに保存されます。正解を重ねた単語は、翌日・3日後・1週間後・2週間後に復習できるように出題間隔が延びます。間違えた単語は次回の優先出題になります。

## スマホで使うには

Webサイトとして公開すれば、iPhone / Android のブラウザで使えます。ホーム画面へ追加すればアプリのように開け、最初に開いた後はオフラインでも使えます。学習記録は端末ごとに保存されます。

## 単語を増やすとき

次のプリントを写真で共有してください。`app.js` の単語データへ追加して、同じアプリで続けて学習できるようにします。
